# Team Lead character blockouts

The newer, more detailed rigged production prototypes are documented in
`docs/ANIMATION-HANDOFF.md` and generated by
`tools/blender/build_detailed_characters.py`. Use those for current integration;
this page preserves the earlier blockout-stage evidence.

`tools/blender/build_character_blockouts.py` creates four original hard-surface
blockouts at metre scale. They follow the Notion silhouette brief: BASTION has
oversized armour and shield; TRACE has a halo, single eye and three stabilizers;
ECHO has paired acoustic dishes; RIFT has a blue V visor and asymmetric plate.
They are **not finished character models**.

Regenerate from the repository root with Blender 5.2.0:

```text
blender --background --python tools/blender/build_character_blockouts.py
```

The script saves one editable `.blend` source and four separate `.fbx` exports under
`Assets/Blacksite/Art/Characters/Blockouts/`. Git LFS tracks those formats.
On 2026-10-17, Blender 5.2 exported and re-imported all four FBXs successfully:
BASTION 14 meshes, TRACE 10, ECHO 12, RIFT 10. Each re-imported mesh had a UV
layer. This confirms file structure, not usable UV layout, visual quality,
rigging, animation, or Unity import.
Inspect each mesh in Blender, refine topology and UVs, then import into Unity.
Check normals, scale, material conversion, corridor/shield clearance, and
animation before calling either model playable. Preserve screenshots of the
editable meshes and UVs for the Graphics submission.

## Animation teammate handoff

See `docs/ANIMATION-HANDOFF.md`. The `.blend` is the editable source. Each FBX
has a distinct mesh set at an origin near the character centre. These are
separate rigid parts with **no armature or clips**; the animation teammate must
rig the humanoids and create a mechanical hierarchy for TRACE. Keep each part's
name and the source file so changes are traceable. Do not assume these exports
are final polished character art.
